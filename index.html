Microservices-Based Real-Time Financial Transaction System

Architected and built a 6-service microservices system (auth, account, transaction, notification, API gateway, service discovery) using Spring Boot 3 and Spring Cloud, with each service owning an independent MySQL database.

Key Features & Technical Architecture:

  • Built real-time transaction notifications using WebSocket, pushing live updates to connected clients instead of relying on polling.
  • Used OpenFeign for inter-service REST communication and Resilience4j circuit breakers to handle downstream service failures gracefully.
  • Decoupled architecture ensuring high fault tolerance, zero single point of failure, and independent horizontal scaling.

Fusion Feast - Full-Stack Restaurant Web Application

Developed a complete full-stack restaurant web application using Java Servlets, JSP, JDBC, and MySQL, deployed on Apache Tomcat 10.1.

Key Features & Technical Architecture:

  • Built 4 RESTful Java Servlets (Menu, Reservation, Admin, Contact) handling HTTP GET/POST requests and returning JSON responses to the frontend.
  • Implemented MVC architecture with DAO pattern using JDBC PreparedStatements to prevent SQL injection vulnerabilities.
  • Applied multithreading in Java to send email and SMS notifications asynchronously without blocking the HTTP response thread.
